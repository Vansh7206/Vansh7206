## 📌 Featured Projects

### [Mumbai Local Train Network Intelligence System](https://github.com/Vansh7206/mumbai-local-train-network)
End-to-end routing and delay prediction system for Mumbai's rail network.
- Dijkstra-based optimal route finder across 100+ stations (Flask API)
- XGBoost delay prediction model (synthetic operational data)
- **Stack:** Python, Flask, XGBoost, NetworkX

---

### [Olist E-Commerce BI System](https://github.com/Vansh7206/ecommerce-rfm-analysis)
RFM customer segmentation system on 96K+ real-world Olist customers.
- Full RFM pipeline: recency, frequency, monetary scoring + segment labeling
- AI-powered NL query engine — ask business questions in plain English
- Power BI dashboard + deployed Streamlit app
- **Stack:** Python, PostgreSQL, Streamlit, Power BI

---

### [Instructor Effectiveness Modeling](https://instructor-effectiveness-modeling.streamlit.app)
Random Forest classifier predicting instructor effectiveness with 96% accuracy.
- Feature engineering, threshold tuning, business-oriented evaluation
- Deployed live on Streamlit
- **Stack:** Python, Scikit-learn, Streamlit · [GitHub](https://github.com/Vansh7206/instructor-effectiveness-modeling)

---

### [Superstore ELT Pipeline](https://github.com/Vansh7206)
Production-style ELT pipeline built on the modern data stack.
- CSV ingestion → S3 → Snowflake → dbt transformations → Power BI dashboard
- dbt models with staging, marts, and data quality tests
- **Stack:** Python, AWS S3, Snowflake, dbt, Power BI

---

### [Telco Customer Churn Prediction](https://github.com/Vansh7206/Telco-Customer-Churn-ML)
End-to-end churn prediction with threshold optimization for business impact.
